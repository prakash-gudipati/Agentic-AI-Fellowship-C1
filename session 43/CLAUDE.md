# CLAUDE.md — Smart Summarizer API

This file is the project briefing. Claude Code reads it before writing any code.

## What we are building
A Smart Summarizer web API. A user pastes text, the app returns a short
TL;DR plus exactly 3 key points, generated by Claude. It ships as a live URL.

## Tech stack
- Python 3.10+
- FastAPI (web framework)
- Anthropic Python SDK (the AI brain) — model: Claude Haiku
- Deploy target: Vercel (serverless Python runtime)

## Architecture (keep it this simple)
- `config.py`   — ALL settings. Reads ANTHROPIC_API_KEY and MODEL from the environment.
- `summarizer.py` — one function `summarize(text) -> dict` that calls Claude.
- `main.py`     — the FastAPI app: GET `/` (HTML form), GET `/health`, POST `/summarize`.
- `api/index.py`— Vercel entry point that imports the app.

## Conventions (non-negotiable)
1. CONFIG FILE SEPARATION — never hardcode a setting in more than one file.
   Every file imports from `config.py`.
2. SECRETS VIA ENVIRONMENT VARIABLES — never write the API key in code.
   Read it from `os.environ`. Never commit `.env`. Commit `.env.example` only.
3. Use type hints. Keep functions small. No external services besides Anthropic.
4. The POST `/summarize` endpoint takes JSON `{ "text": str }` and returns
   `{ "tl_dr": str, "key_points": [str, str, str] }` — exactly 3 key points.

## Out of scope (do NOT add)
- No database. No auth. No frontend framework. Plain HTML only.
